# Audio Mixing 使用说明

把局域网里几台设备的声音，送到你指定的耳机 / 音箱里。
只走局域网，不经过任何服务器，不需要登录，不需要账号。

---

## 一、装什么

| 文件 | 装在哪 | 用途 |
|---|---|---|
| `AudioMixing.exe` | 每台电脑 | 主程序，双击运行 |
| `AudioMixing-mic.apk` | 安卓手机 | 把手机的声音送出去；也可以让手机当喇叭 |

两台电脑都要装。第一次运行 Windows 会弹防火墙提示，点「允许」。
没弹或点错了：右键右下角托盘图标 → 「放行防火墙（需管理员）」。

**程序别放下载文件夹**：防火墙规则绑目录，换目录就要重新放行一次。
建议固定放在一处，比如 `D:\AudioMixing\`。

---

## 二、怎么用

### 1. 电脑之间互传声音

在**要听的那台**上建一条路由：

```
控制台 → 路由 → 从 [对方电脑的名字] 到 [本机] → 添加
```

对方的视频、音乐、游戏声音就进你的耳机了。反过来传就再建一条反方向的。
**两台都要开着程序。**

### 2. 广播（一对多）

一个人说，很多人听。

```
说话那台：控制台 → 打开「广播我的声音」
收听那几台：控制台 → 打开「只听」
```

**广播和只听互斥** —— 开了一个会自动关掉另一个。要么说，要么听。

广播播什么由「音源清单」决定。想广播这台电脑正在放的声音，
就在清单里勾上你在用的那块输出设备（扬声器或耳机）。**一块都没勾 = 不广播任何东西**（发送 0 包）。

**广播端口与点对点端口是分开的**：广播走 47832，点对点走 47831，各自准入、互不影响。
新旧版本混装时（例如电脑 2.42.2 + 手机 2.27），旧设备没有广播端口，面板会把它的名字列出来并说明
「收不到广播，请升级对端」，**不会默默静音**。手机 2.29 起还兼容旧电脑从 47831 发来的广播。

### 2.1 三档「性能预算」（流畅 / 均衡 / 高音质）

面板顶部的「音质」三颗按钮，本质是给这条链路多少性能预算，延迟只是副作用：

| 档位 | 适合 | 实测重采样 CPU（单核） | 抖动缓冲起点 / 区间 |
|---|---|---|---|
| 流畅 | 老机器、低配机器 | ≈ 8% | 40 ms / 20–90 ms |
| 均衡（默认） | 大多数机器，等同旧版行为 | ≈ 18% | 55 ms / 25–150 ms |
| 高音质 | 机器够好，愿意吃性能换音质 | ≈ 28% | 80 ms / 40–200 ms |

两端各自可设；**不一致时按较低那档协商生效**，面板会显示「协同生效 X」。
老配置没有这个键 → 自动落在「均衡」，听感不变。Opus 码率/复杂度只在 Opus 编码时生效，
PCM16 下三档主要差在包长（帧长）、抖动缓冲和重采样质量。

### 2.2 USB 有线模式（数据线也能当局域网）

手机和电脑用数据线连起来、手机系统里打开「USB 网络共享」，数据线就是一条网线：
不依赖 Wi-Fi、不受路由器隔离影响，延迟更稳。

- 电脑端「详细 → 设置 → 点对点链路」：`自动` / `有线优先` / `Wi-Fi 优先`。
  `自动` 的排序是 **USB 网络共享 > 网线 > Wi-Fi**（2.46.5 起；之前自动可能仍选 Wi-Fi）。
- 手机端「⚙ 设置 → 点对点链路」同样三档，并显示 USB 网络共享是否已开启，
  带一个「🔌 打开 USB 网络共享」按钮直接跳到系统页。
- **插上 USB 自动触发**（电脑端设置里，默认开）：插线后电脑用 `adb` 启动手机 App
  并尝试打开 USB 网络共享，不用再手动去系统设置里点。前提：
  1. 手机开启一次「开发者选项 → USB 调试」，并在弹窗里允许这台电脑；
  2. 电脑有 `adb.exe`（Android SDK Platform-Tools，或把 `adb.exe` 放到程序目录 /
     `platform-tools\` 下）。
  找不到 adb 时这一项什么都不做，仍可手动打开 USB 网络共享。
  普通 App 没有权限自己开关 USB 共享；spacedesk 的 USB 模式也是同样的原理。

### 2.3 一台电脑接多个耳机（多耳机页）

**简洁**（侧边栏「简洁」）：每块输出设备一张卡片，点一下变蓝＝开始放（默认放桌面混音），
再点一下变暗＝停。系统默认设备是「直出」，固定蓝、不可点灭。

**详细**（侧边栏「详细」）：一张「音源 × 输出设备」矩阵。

- 行＝音源（桌面混音 / 正在出声的 App / 在线远端设备），列＝本机输出设备。
- 蓝色格子＝这条音源混进这台设备；点一下接通/断开。
- 点第一行（设备名）＝整列接通/断开；点第一列（音源名）＝整行接通/断开。
- 最后一行「折叠设备…」收起整列，最后一列「折叠音频…」收起整行；
  折叠项在表格下方「已折叠」里点一下恢复。
- 左上「音频全开」＝所有格子接通；右下「音频全关」＝所有格子断开。
- 某一路的音量/延迟：点亮这一列任意一格后，点列头的 🎚。

改完立刻生效，没有「应用」按钮。系统默认设备由 Windows 直出，不在矩阵里。

### 3. 手机当喇叭（App 版，推荐）

把手机变成电脑的音响，音质比网页版好（手机端用原生播放，缓冲只有 150 毫秒）。

```
1. 电脑上打开「广播我的声音」（或让某个路由把声音送到手机）
2. 手机装 AudioMixing-mic.apk，打开
3. 在地址栏填电脑的局域网地址（电脑监控页上显示的那个，形如 192.168.0.108:17800）
4. 点「🔊 当喇叭（放电脑的声音）」→ 手机开始放电脑的声音

> 界面上的「🔍 扫描局域网」依赖电脑端的发现广播，有些网络环境（访客网络、
> 手机省电策略）收不到，暂时搁置。**扫不到就直接手输地址**，功能不受影响。
```

**注意**：
- 「当喇叭」和「发送声音」是**互斥**的 —— 开了一个会自动停掉另一个，
  否则手机会一边放电脑的声音、一边把这段声音采回去，对方就听到自己的回音
- 手机没装 App 时，扫网页上的二维码也能当喇叭（网页版，延迟略高）

### 4. 手机的声音送到电脑

**走 Wi-Fi（推荐）**

```
1. 手机连同一个 Wi-Fi
2. 手机浏览器打开 http://<电脑IP>:17800/app ，装那个 APK
3. 打开手机上的 Audio Mixing，点「发送系统声音」或「发送麦克风」
4. 电脑上：控制台 → 打开「本机直通」
```

**走蓝牙（手机不用装东西）**

```
1. 手机和电脑配对
2. 电脑上：控制台 → 蓝牙 → 点「连接」
3. 手机蓝牙设置里确认「媒体音频」是勾上的
```

蓝牙进来的声音由 Windows 直接送到默认播放设备 ——
**听不听得到，取决于 Windows 的默认输出设备选对没有**，和本程序无关。

## 三、看什么（监控窗）

双击托盘图标，或浏览器打开 `http://127.0.0.1:17800/monitor`。

```
从谁        给谁           通道      状态      数据量    速率
书房电脑    全网设备(广播)   [广播]    正在广播   9.3 MB   1535 KB/s
客厅音箱    本机耳机        [点对点]   正在接收   13.7 MB  400 ms
```

- **通道**：`广播` 一对多，`点对点` 两台之间，`蓝牙` 手机走蓝牙
- **残留**：某条已删除的路由还挂着，8 秒内会自己消失
- **每行右边「断开」**：广播 → 停止广播；点对点 → 静音那条路由；蓝牙 → 断开手机
- **诊断**：生成完整体检报告，排查时复制给对方看

## 四、常见问题

**对方听不到我的声音**
1. 两台都开着程序吗
2. 路由建了吗（监控里应有 `点对点` 一行，数据量在涨）
3. 对方防火墙放行了吗（诊断 → 网络自检 → 看「入站 TCP/UDP 放行」）

**手机端一直 0 台设备 / 电脑发现不了手机**
先看手机空列表里那行**发现自检**（一直收不到信标才会出现）：
- `收 0 / 自己 0`：本机收不到组播/广播。多半是路由器开了「AP 隔离 / 客户端隔离」
  或丢了组播。换一个 Wi-Fi，或在手机「⚙ 设置 → 发现」里**手动填电脑 IP**
  （电脑面板顶部那个，如 `192.168.2.100`），App 会每 2 秒直接给它单播信标。
- `收 > 0` 但列表还是空：说明收到了别人的帧但不是我们的协议，点「🩺 诊断」复制自检。
- 电脑列表里卡片只有 IP、带「手动添加」标签：那是手动兜底，不是自动发现成功。

**注意**：两端版本尽量一致（电脑 2.46.6+ / 手机 2.31.5+）；手机第一次打开会问
「附近的设备」权限，允许它（Android 16 的本地网络保护会用到）。

**听到自己声音的回音**
两台互相传时，如果各自「播放设备」和「采集设备」是同一块，
对方的声音会被采到又发回去。**让听和录用两块不同设备**即可
（例如用扬声器外放听，耳机只当麦克风）。

**开只听之后点对点没声音**
这一版已修好。只听只影响广播，不影响点对点。

**声音断续、越来越卡**
两台都换成 `opus` 编码（控制台 → 编码）：每路从 1536 KB/s 降到十几 KB/s。

**托盘图标不见了**
看右下角小箭头，可能被折叠进去了。

**双击没反应 / 报错**
说明已有节点在跑，程序会自动打开它的监控窗。
要彻底重启：右键托盘 → 停止服务并退出，再双击。

## 五、几个数字（判断是否正常）

| 项目 | 正常值 |
|---|---|
| 未压缩（pcm_s16）每路带宽 | 约 1536 KB/s |
| Opus 每路带宽 | 十几到几十 KB/s |
| 局域网延迟 | 1~5 毫秒 |
| 接收缓冲 | 25~150 毫秒之间自适应 |
| 占用端口 | 17800 网页、17801 手机、17830 发现、47831 点对点音频、47832 广播（只有发现端口需要两端一致；广播与点对点各判各的） |

## 六、卸载

```
1. 右键托盘图标 → 停止服务并退出
2. 删掉程序文件夹
3. （可选）删掉 %APPDATA%\AudioMixing\    ← 设置和记录都在这里
4. （可选）防火墙里删掉名字以 Audio Mixing 开头的规则
```
