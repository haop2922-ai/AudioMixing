详情与排查
安卓 Chrome / Edge：用 http 的局域网地址打开就能直接用。
iPhone 的 Safari 必须用 https 打开才能拿到麦克风（只当接收方时 http 一般也能听）。
传不了「手机正在播放的音乐」：浏览器拿不到系统正在放的声音（系统限制），这里传的只能是麦克风里的声音。
电脑只转发协商信息，音频是两台手机直连 —— 协商完成后，关掉电脑声音照样在传。
两台手机要在同一个 Wi-Fi；连不上就先查这一条。
