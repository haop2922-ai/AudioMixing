为什么手机上装着浏览器、却不能被添加成设备？
Audio Mixing 要求每台设备都运行一个节点程序。手机上的浏览器只能打开这个页面 （当遥控器），它本身不是一个节点，所以：
· 手机可以看这个控制台、可以当"音响"播放（如果装了客户端）
· 手机不能被 ping 通，也不能被添加成设备——它上面没有任何东西在监听

想分享手机的声音，先把手机声音送进任意一台电脑，再交给 Audio Mixing：
· 蓝牙：手机蓝牙连电脑，或使用 Phone Link 的声音投射
· 数据线：手机耳机口 → 电脑 Line-in / USB 声卡
声音一旦进入电脑，WASAPI 环回采集会自动抓到它，在路由里把"声音来自"选成那台电脑即可。

Android 10+ 与 iOS 强制要求用户授权才能采集其它 App 的声音， 这是系统隐私策略，任何程序都无法绕过——所以手机端需要单独开发一个 App。

点「连接」后，手机就把它当成一个蓝牙音箱（手机上会出现这个电脑的名字，选中它即可）。 手机蓝牙设置里确认 「媒体音频」 已打开；声音会由 Windows 直接播到默认输出，本机不需要再加音源。 要把手机声音转发到别的设备/频道，才到 「频道（局域网广播）→ 音源」 选中 麦克风 (<手机名> A2DP SNK) 并勾「广播我的声音」；「本机直通」会和系统播放重复，慎用。

像收音机一样：一台机器「广播」，其它机器「收听」即可听到它，不需要配路由。
收听时不发送本机声音（电台不会反过来播音），所以不会产生回声——这正是它和"双向路由"的区别。
多台一起广播 → 收听方会把它们混在一起播出（多台电脑的声音汇到一副耳机）。
两个都勾 = 会议模式（互相都听得到）。若收发用的是同一块声卡，那会和双向路由一样产生回声。 接手机（蓝牙，手机不用装 App）：先用系统里的「Bluetooth Audio Receiver」把手机连上（手机把它当成音箱）， 然后到 设置 → 采集设备 选 麦克风 (<手机名> A2DP SNK)，再勾「广播我的声音」。 蓝牙是点对点的，一块适配器同时只能接一路手机；要同时接多台，就插多个 USB 蓝牙适配器。 音源默认是系统声音（这台电脑正在播放的一切）。手机蓝牙进来的声音是单独的 麦克风 (<手机名> A2DP SNK) 采集设备，要在音源里单独选（或开「智连」自动播放）； 输出跟着 Windows 默认播放设备。 要单独指定某块声卡/麦克风、换输出设备、改抖动缓冲或编码，点右上角 详细 →「频道」的音源 /「设置」。
这三个开关会被记住：下次启动 Audio Mixing 时自动恢复到你现在选的状态。

设置

静音档乘 1.0 时耳机侧相当于满格放，从外放档切到静音档可能明显变响； 滑杆本身改系统媒体音量的 App（B 站、抖音这类）在静音档里调音量无效，要用滑杆请切外放档； 内部增益类 App（YouTube 播放器这类）不受影响。
诊断
上面是维护工具：连不上先「放行防火墙」；连上但没声音先「恢复声音」；要发问题就点「诊断」。
抖动缓冲越大越抗网络抖动、延迟也越高。有线或 5GHz 可以调到 40ms 以下。
