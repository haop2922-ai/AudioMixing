# Audio Mixing 使用说明

把局域网里几台设备的声音，送到你指定的耳机 / 音箱里。
只走局域网，不经过任何服务器，不需要登录，不需要账号。

---

## 一、装什么

| 文件 | 装在哪 | 用途 |
|---|---|---|
| `AudioMixing.exe` | 每台电脑 | 主程序，双击运行 |
| `AudioMixing-mic.apk` | 安卓手机 | 把手机的声音送出去；也可以让手机当喇叭 |

两台电脑都要装。第一次运行 Windows 会弹防火墙提示，点「允许」。
没弹或点错了：右键右下角托盘图标 → 「放行防火墙（需管理员）」。

**程序别放下载文件夹**：防火墙规则绑目录，换目录就要重新放行一次。
建议固定放在一处，比如 `D:\AudioMixing\`。

---

## 二、怎么用

### 1. 电脑之间互传声音

在**要听的那台**上建一条路由：

```
控制台 → 路由 → 从 [对方电脑的名字] 到 [本机] → 添加
```

对方的视频、音乐、游戏声音就进你的耳机了。反过来传就再建一条反方向的。
**两台都要开着程序。**

### 2. 广播（一对多）

一个人说，很多人听。

```
说话那台：控制台 → 打开「广播我的声音」
收听那几台：控制台 → 打开「只听」
```

**广播和只听互斥** —— 开了一个会自动关掉另一个。要么说，要么听。

广播播什么由「音源清单」决定。想广播这台电脑正在放的声音，
就在清单里勾上你在用的那块输出设备（扬声器或耳机）。

### 3. 手机当喇叭（App 版，推荐）

把手机变成电脑的音响，音质比网页版好（手机端用原生播放，缓冲只有 150 毫秒）。

```
1. 电脑上打开「广播我的声音」（或让某个路由把声音送到手机）
2. 手机装 AudioMixing-mic.apk，打开
3. 在地址栏填电脑的局域网地址（电脑监控页上显示的那个，形如 192.168.0.108:17800）
4. 点「🔊 当喇叭（放电脑的声音）」→ 手机开始放电脑的声音

> 界面上的「🔍 扫描局域网」依赖电脑端的发现广播，有些网络环境（访客网络、
> 手机省电策略）收不到，暂时搁置。**扫不到就直接手输地址**，功能不受影响。
```

**注意**：
- 「当喇叭」和「发送声音」是**互斥**的 —— 开了一个会自动停掉另一个，
  否则手机会一边放电脑的声音、一边把这段声音采回去，对方就听到自己的回音
- 手机没装 App 时，扫网页上的二维码也能当喇叭（网页版，延迟略高）

### 4. 手机的声音送到电脑

**走 Wi-Fi（推荐）**

```
1. 手机连同一个 Wi-Fi
2. 手机浏览器打开 http://<电脑IP>:17800/app ，装那个 APK
3. 打开手机上的 Audio Mixing，点「发送系统声音」或「发送麦克风」
4. 电脑上：控制台 → 打开「本机直通」
```

**走蓝牙（手机不用装东西）**

```
1. 手机和电脑配对
2. 电脑上：控制台 → 蓝牙 → 点「连接」
3. 手机蓝牙设置里确认「媒体音频」是勾上的
```

蓝牙进来的声音由 Windows 直接送到默认播放设备 ——
**听不听得到，取决于 Windows 的默认输出设备选对没有**，和本程序无关。

## 三、看什么（监控窗）

双击托盘图标，或浏览器打开 `http://127.0.0.1:17800/monitor`。

```
从谁        给谁           通道      状态      数据量    速率
2024TSJ    全网设备(广播)   [广播]    正在广播   9.3 MB   1535 KB/s
2025BJB    本机耳机        [点对点]   正在接收   13.7 MB  400 ms
```

- **通道**：`广播` 一对多，`点对点` 两台之间，`蓝牙` 手机走蓝牙
- **残留**：某条已删除的路由还挂着，8 秒内会自己消失
- **每行右边「断开」**：广播 → 停止广播；点对点 → 静音那条路由；蓝牙 → 断开手机
- **诊断**：生成完整体检报告，排查时复制给对方看

## 四、常见问题

**对方听不到我的声音**
1. 两台都开着程序吗
2. 路由建了吗（监控里应有 `点对点` 一行，数据量在涨）
3. 对方防火墙放行了吗（诊断 → 网络自检 → 看「入站 TCP/UDP 放行」）

**听到自己声音的回音**
两台互相传时，如果各自「播放设备」和「采集设备」是同一块，
对方的声音会被采到又发回去。**让听和录用两块不同设备**即可
（例如用扬声器外放听，耳机只当麦克风）。

**开只听之后点对点没声音**
这一版已修好。只听只影响广播，不影响点对点。

**声音断续、越来越卡**
两台都换成 `opus` 编码（控制台 → 编码）：每路从 1536 KB/s 降到十几 KB/s。

**托盘图标不见了**
看右下角小箭头，可能被折叠进去了。

**双击没反应 / 报错**
说明已有节点在跑，程序会自动打开它的监控窗。
要彻底重启：右键托盘 → 停止服务并退出，再双击。

## 五、几个数字（判断是否正常）

| 项目 | 正常值 |
|---|---|
| 未压缩（pcm_s16）每路带宽 | 约 1536 KB/s |
| Opus 每路带宽 | 十几到几十 KB/s |
| 局域网延迟 | 1~5 毫秒 |
| 接收缓冲 | 25~150 毫秒之间自适应 |
| 占用端口 | 17800 网页、17801 手机、47830 发现、47831 音频 |

## 六、卸载

```
1. 右键托盘图标 → 停止服务并退出
2. 删掉程序文件夹
3. （可选）删掉 %APPDATA%\WaveLink\    ← 设置和记录都在这里
4. （可选）防火墙里删掉名字以 Audio Mixing 开头的规则
```
