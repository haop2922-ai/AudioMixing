## 已知限制（照实写）

1. **多设备输出不会自动排除"正在响的设备"** ✗
   Windows 默认输出那块设备本来就在响，如果也勾上，会听到原声加一份晚到的
   复制，两路叠加互相抵消，听感是金属音。
   **规避方法：不要勾 Windows 正在用的那块输出设备。**

2. **手机端局域网扫描暂停** ✗
   依赖电脑端的发现广播，部分网络环境（访客网络、手机省电策略）收不到。
   **规避方法：手输电脑地址**（监控页上有显示）。二维码不受影响。

3. **手机当喇叭是 24kHz 单声道** ✗
   为治手机播放断续做的取舍（47 KB/s）。放歌、看视频够用，
   但不如电脑之间的点对点（完整 48kHz 立体声）。

4. **只有 Windows + Android** ✗
   没有 macOS / Linux / iOS，没有 USB 连接模式，没有跨网中继（有意不做）。

5. **没有代码签名** ✗
   Windows 首次运行会提示"未知发布者"，点"仍要运行"即可。

6. **没有自动更新** ✗
   换版本要手动替换 exe。

7. **防火墙规则绑路径** ✗
   程序换目录后要重新点一次托盘里的「放行防火墙」。

## 怎么装

```
1. 两台电脑都放 AudioMixing.exe，双击运行
2. 右键托盘图标 → 放行防火墙（需管理员）→ 弹窗点「是」
3. 手机装 AudioMixing-mic.apk（或扫电脑上的二维码）
4. 详细用法见 使用说明.md
```
