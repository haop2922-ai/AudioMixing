# v1.10：电脑面板的视觉和手机端统一

用户原话：

> 看到了手机 app 的 UI 我觉得电脑的太丑。像手机保持类似主题。

**做法是照抄，不是另创一套。** 权威定义是 `audiomixing/ui/phone.html` 的 `:root`，
电脑端（`audiomixing/ui/index.html`）的令牌逐个与它相同，并且有回归测试钉住
（`TestThemeParityWithPhone`：谁把电脑端改回自己的配色，测试直接红）。

---

## 一、主题令牌（两边完全一致）

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--bg` | `#070b12` | 底色 |
| `--card` | `rgba(255,255,255,.045)` | 卡片底 |
| `--line` | `rgba(255,255,255,.09)` | 描边 |
| `--fg` | `#eaf1fb` | 主文字 |
| `--dim` | `#8ea0b8` | 次要文字（标签 12.5px） |
| `--acc` | `#38bdf8` | 主色（亮蓝） |
| `--acc2` | `#6366f1` | 渐变另一端（靛） |
| `--ok` | `#34d399` | 正常/在线 |
| `--warn` | `#fbbf24` | 警告 |
| `--err` | `#f87171` | 错误 |

底色不是纯色，是手机端那两层光晕（照搬）：

```css
background:
  radial-gradient(120% 70% at 50% -10%, #14324d 0%, transparent 60%),
  radial-gradient(90% 60% at 110% 110%, #2a1b52 0%, transparent 55%),
  var(--bg);
```

电脑端另外保留几个**同义映射**（旧类名还在用，不引入新颜色）：
`--card2: rgba(255,255,255,.03)`、`--line2: rgba(255,255,255,.16)`、
`--dim2:#7a8ba3`、`--bad: var(--err)`。

## 二、照抄的具体做法

| 元素 | 电脑端取值 | 手机端取值 |
|---|---|---|
| 卡片 | `border-radius:16px` + `1px solid var(--line)` | 同 |
| 设备卡片 | `border-radius:16px`，两列（`minmax(290px,1fr)` 自动列） | 16px 单列 |
| 主按钮 | `linear-gradient(140deg,var(--acc),var(--acc2))` + `color:#04121f` + `0 8px 20px rgba(56,189,248,.22)` | 同（`.main`） |
| 状态胶囊 | `border-radius:999px`、半透明描边（绿 `--ok` / 黄 `--warn` / 红 `--err`） | 同（`.pill`） |
| 大状态圆环 | 150px，`stroke-width:8`，`stroke:url(#ringGrad)`（`--acc→--ok` 渐变），`stroke-dasharray:326.7` | 同（`.ring`，手机端 230px） |
| 22 段电平条 | `i` 元素 ×22、`border-radius:3px`、亮起 `linear-gradient(180deg,var(--acc),var(--ok))` | 同（`.bars`，常量都是 22） |
| 分段控件 | 圆角 14px 容器 + 圆角 11px 按钮，选中项渐变底 + 深色字 | 同（`.seg`） |
| 折叠详情 | `<details>` + `▸/▾`（由 CSS `::before` 出）+ 12.5px `--dim` | 同 |
| 字号/行高 | `font:15px/1.5 -apple-system,"Segoe UI","Noto Sans SC",…` | 同 |

## 三、电脑是宽屏，所以排布不一样（令牌照抄、用起宽度）

- **设备卡片两列**：`#deviceCards{grid-template-columns:repeat(auto-fit,minmax(290px,1fr))}`
- **传输行 / 状态行两列**（≥1200px）：`#streamsBox`、`#statusRows` 改成 `auto-fit` 网格
- **浏览密度三档用词与手机端一致**：`简洁` / `详细`（分段控件）+ `监控`（同一个视觉语言的按钮）

## 四、信息排布（保留 v1.9 的全部功能）

- `③ 本机状态` 顶部新增：**大状态圆环 + 22 段电平条**
  - 有本机播放时：数字 = 播放电平 %，状态写"本机正在出声 / 有数据，但现在是静音"
  - 只在接收时：数字 = 链路评分，状态写"正在接收 N 路声音"
  - 都没有：`空闲：没有声音在流`
- `② 设备与路由`、`🚀 快速上手`、告警框（红/黄）、版本提示、音源体检全部保留，只是换了皮肤。
