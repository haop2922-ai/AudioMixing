# 已知限制与边界

本文档说明 AudioMixing 当前版本的能力边界，以及短期内不会支持的场景。
这些不是 bug，是有意识的设计取舍。

## 平台与网络

1. **只有 Windows + Android**
   没有 macOS / Linux / iOS。没有跨网中继、没有云服务器、没有账号体系 ——
   这些不是待办，而是本项目的定位：只在同一局域网内工作。

2. **发现依赖同一网段与路由器配合**
   局域网发现走 UDP 组播/广播。访客网络、开了 AP 隔离的路由器、部分企业 Wi-Fi
   会拦截这些包，表现是“互相看不见”。可以在面板里手动填对方 IP 兜底；
   二维码不受影响。

3. **USB 网络共享需要手机端手动打开**
   Android 第三方应用没有开关 USB 网络共享的权限，只能提示或通过 ADB 自动触发。
   不需要 root，但需要用户在手机下拉通知里点一次「USB 网络共享」。

## 音频

4. **手机网页版听众可选三档，但不是无损**
   省电 24kHz 单声道 / 均衡 48kHz 单声道 / 音质 48kHz 立体声。
   默认是均衡档；弱 Wi-Fi 或长时间使用时建议切省电。
   手机 App 听众走点对点 RTP，固定 48kHz 立体声，不受这三档影响。

5. **一块声卡只有一个写入者**
   同一块输出设备上的多条路由会先混音再写一次，避免两个播放端互相踩。
   这是设计约束，不是可配置项。

6. **广播与「只听」互斥**
   同一台设备要么广播、要么只听，结构上避免形成回环。

7. **电脑之间是完整 48kHz 立体声，但受网络质量影响**
   抖动缓冲、丢块与时钟偏移都会影响听感；先在监控页看数据，再决定换有线/5GHz。

## 交付与运行

8. **没有代码签名**
   Windows 首次运行会提示“未知发布者”，点“仍要运行”即可。

9. **没有自动更新**
   换版本需要手动替换 exe / 安装新 APK。

10. **防火墙规则按程序路径绑定**
    程序换目录后，需要在托盘菜单里重新点一次「放行防火墙」。

11. **「锁定默认播放设备」是可选动作**
    程序退出时会还原；异常退出（断电/强杀）后，面板会给出还原入口。

12. **网页版听众依赖浏览器**
    需要浏览器保持页面存活并允许自动播放；手机锁屏或浏览器省电策略可能暂停播放。
