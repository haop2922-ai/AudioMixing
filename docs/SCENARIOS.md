# 场景教程：办公室「一副耳机收 5 台设备」、家庭「两人互听」

本文只讲操作，不涉及原理。原理见 [`DESIGN.md`](DESIGN.md)。

---

## 场景 A：办公室——3 个手机 + 2 台电脑，只要一副耳机，且不能外放

### 前提

* 5 台设备在同一个 Wi-Fi/局域网（公司网通常可以，除非开了「AP 隔离」）。
* 插耳机的那台电脑（下称 **主机**）运行 WaveLink。
* 其它 4 台设备运行 WaveLink 并采集自己的声音。

### 步骤

1. **主机**（插耳机的那台，比如你的笔记本）：

   ```powershell
   python -m audiomixing serve --name "我的笔记本" --sink-device "WH-1000XM5"
   ```

   `--sink-device` 里的关键字用 `python -m audiomixing devices` 查到的名字片段即可。

2. **其它电脑**（同样接耳机的声音源）：

   ```powershell
   python -m audiomixing serve --name "台式机"
   ```

3. **手机**：见 [`PLATFORM-NOTES.md`](PLATFORM-NOTES.md) 的移动端说明（需要系统授权采集）。
   在手机端完成前，可以先用下面的「无手机降级方案」。

4. 在**主机**上打开 `http://127.0.0.1:17800`：

   * 「① 局域网内的设备」应能看到所有节点（显示在线 + 各自的采集/播放设备）；
   * 「② 路由」：声音来自 = 全部 4 台 + 本机；播放在 = 我的笔记本；音量 1.0；添加路由。

5. 验证：让某台电脑放音乐/某台手机来通知，耳机里应该同时有。

### 无手机降级方案（今天就能用）

手机不装 App 也行，只要手机的声音能进到某台电脑：

* **蓝牙（Phone Link / 蓝牙音频接收）**：把一台手机通过蓝牙连到某台电脑，手机声音进入
  这台电脑的播放链，WaveLink 再把它和其它声音一起送到你的耳机。缺点是蓝牙一次只能连一台。
* **USB / 3.5 mm 音频线**：手机耳机口（或 USB 声卡）输出接到电脑的 Line-in。
* 之后在路由表里，把这台电脑当作那些手机的「声音来源」。

### 常见坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 设备列表只有自己 | 公司 Wi-Fi 开了 AP 隔离 / 禁组播 | 在控制台「手动添加设备」里填对端 IP；对端也加本机 IP |
| 耳机里没声音 | 主机的采集设备被设成了麦克风而不是系统声音 | 路由里显式指定「输出设备」，或确认设备列表里带 `[loopback]` 的项 |
| 声音小 | 源设备系统音量低 | 路由音量调到 1.5–2.0；源设备系统音量也别太低 |
| 有断续 | Wi-Fi 抖动大 | 把「抖动目标」调大（控制台设置里 25–150 ms），或改用 5 GHz |
| 有回声 | 同一台机器既采集又播放到同一个扬声器 | 主机的采集源选「麦克风/其它设备」，或用耳机（采集的是扬声器端点，不会自我回环） |

## 场景 B：家庭——我的电脑 ↔ 伴侣的耳机，互听但不吵到家人

### 目标

* 我的电脑声音 → 伴侣的耳机（她听我的）
* 伴侣的电脑声音 → 我的耳机（我听她的）
* 家人：什么都不加，就什么都听不到（因为不在路由目标里）

### 步骤

1. 两台电脑各跑一个节点：

   ```powershell
   :: 我的电脑
   python -m audiomixing serve --name "我的电脑" --sink-device "我的耳机"

   :: 伴侣的电脑
   python -m audiomixing serve --name "伴侣的电脑" --sink-device "她的耳机"
   ```

2. 在任意一台打开控制台，加两条路由：

   | 声音来自 | 播放在 | 说明 |
   | --- | --- | --- |
   | 我的电脑 | 伴侣的电脑 | 她听我的 |
   | 伴侣的电脑 | 我的电脑 | 我听她的 |

   路由表会被自动推送到两台机器，两边同时生效。

3. 想「客厅也听到」时，再加一条：声音来自 = 我的电脑 + 伴侣的电脑，播放在 = 客厅音箱。
   不需要时删掉这条即可，家人的设备从头到尾都不在列表里。

### 隐私相关的两个开关

* **只在指定设备响**：这是路由模型的天然结果——不在 `to` 列表里的设备收不到任何包。
* **不想被打扰**：把某条路由「静音」，音频立刻停（源端停止采集发送），
  恢复时取消静音即可；也可以直接删路由。

## 场景 C：一个人的多设备（最简用法）

同一台电脑上开一个节点，把所有**别的**设备路由到它：

```
手机（蓝牙进电脑）─┐
另一台笔记本 ──────┤──→ 我的笔记本（耳机）
工作手机 ──────────┘
```

只加一条路由：来源 = 全部，目标 = 我的笔记本。

## 快速排查命令

```powershell
python -m audiomixing doctor          # 本机链路自检（采集→网络→播放）
python -m audiomixing devices         # 设备名清单
python -m audiomixing status          # 现在有哪些设备、哪些路由、流量多少
python -m audiomixing status --json   # 给脚本/工单用
```

`doctor` 第 6 项会打印「真机回路测试」的 rms：如果接近 0，说明这台机器此刻没有在播放
任何声音，属于正常（不是故障）。
