# 源码包说明

本仓库本身即可直接构建，不需要额外的“源码包”。如果你拿到了一个
`AudioMixing-源码-<PC版本>-<手机版本>.zip`，它的结构如下：

| 目录 | 内容 |
|---|---|
| `电脑端/` | Python 源码（`audiomixing/`）、测试（`tests/`）、构建与验收工具（`tools/`）、启动脚本、根文档 |
| `手机端/` | Android 工程源码：`android/app/src`、`android/testapp/src`、`android/tools`、Gradle 配置 |
| `文档/` | Markdown 文档（不含截图与自检输出） |

## 构建

电脑端与手机端的完整构建步骤见仓库根目录 `README.md` 的「怎么自己编译」，
以及本目录下的 `构建与分发.md`。

- 电脑端：`python tools/build_nuitka.py --test`，产物 `dist_nuitka/AudioMixing.exe`。
- 手机端：在 `android/` 下准备 `local.properties`（写 `sdk.dir`），
  然后 `gradle assembleDebug`。

## 刻意排除

`release/`、`dist_nuitka/`、`版本备份/`、`Mac版交接/`、`promo/`、`dev/`、`.tmp/`、
`docs/screenshots`、`docs/selfcheck`、`docs/参赛材料-截图`、`tools/installer_payload`、
`tools/testmedia`、`tools/adb-logs`、`build/`、`.gradle/`、`out/`、`__pycache__/`、
`*.apk`、`*.pyc`、`android/local.properties`。

这些是构建产物、本机快照或体积较大的素材，统一走 GitHub Releases，不进代码仓库。
