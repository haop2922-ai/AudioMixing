# Audio Mixing 视频拍摄脚本

**成品时长**：6~8 分钟（可剪成 60 秒预告片 + 完整版）
**风格建议**：录屏为主（真机演示），人物出镜只用开头结尾各 5 秒
**核心卖点一句话**：把局域网里几台设备的声音，送到你指定的耳机 / 音箱里；不经过任何服务器。

---

## 拍摄前准备清单

### 设备

| 用途 | 数量 | 说明 |
|---|---|---|
| 电脑 A（演示发送方） | 1 | 装 `AudioMixing.exe`，接一副耳机（或外放） |
| 电脑 B（演示接收方） | 1 | 装 `AudioMixing.exe`，接一副耳机 |
| 安卓手机 | 1~2 | 装 `AudioMixing-mic.apk`（演示"当喇叭"和"送声音"） |
| 耳机 / 音箱 | 2~3 | 至少两副，用来演示"一台电脑推多个耳机" |
| 同一局域网 | — | 两台电脑 + 手机连同一个 Wi-Fi（手机别用流量） |

### 软件

```
两台电脑：AudioMixing.exe（20.3 MB 单文件，放桌面即可）
手机    ：AudioMixing-mic.apk
录屏    ：OBS / Windows 自带录屏（Win+G）
```

### 演示前必做（否则录出来是失败的）

```
□ 两台电脑都双击运行 AudioMixing，托盘图标出现，面板能打开
□ 右键托盘图标 → 放行防火墙（需管理员）→ 点「是」← 不做这步对方听不到
□ 手机和电脑连同一个 Wi-Fi
□ 手机装好 APK 并打开过一次
□ 关掉杀毒软件的弹窗（录制时弹窗很难看）
□ 屏幕上的真实 IP、机器名如果不想露，录完打码
```

### 【第 2 段】功能演示（核心，占全片 60%）

#### 2.1 电脑之间互传声音｜0:50–1:50

**画面**：电脑 A 的屏幕 → 打开控制台 → 路由区域

**操作步骤（照着点）**：
```
1. 电脑 B（要听的那台）：打开控制台
2. 「路由」区 → 从 [电脑 A 的名字] 到 [本机] → 点「添加」
3. 电脑 A 播放任意音乐/视频
4. 电脑 B 的耳机里响起同一首歌
```

**台词**：
> "先看最基本的：电脑之间互传声音。
> 在要听的那台上建一条路由 —— 从对方电脑，到本机，添加。
> 好了，现在对方在放什么，我这边耳机里就是什么。
> 反过来想传回去，就再建一条反方向的。"

**拍摄要点**：
- 特写路由添加的那一下点击（这一步是用户最需要看清的）
- 录一段"耳机真的在响"的证据（把耳机凑近麦克风）
- 监控窗里那一行 `点对点 / 正在接收 / 数据量在涨` 要拍到

#### 2.2 广播：一个人说，很多人听｜1:50–2:50

**画面**：三台设备（两台电脑 + 一台手机），演示一对多

**操作步骤**：
```
1. 说话那台：打开「频道 → 广播我的声音」
2. 收听的两台：打开「只听」
3. 对着电脑 A 说话（或用它的麦克风放歌）
4. 另外两台同时听到
```

**台词**：
> "第二种用法是广播。一个人说，很多人听。
> 说话那台打开「广播我的声音」，收听的那几台打开「只听」——
> 注意这两个是互斥的，开了一个会自动关掉另一个：要么说，要么听，不会打架。
> 这个模式下，音源也可以不是麦克风 —— 想广播电脑正在放的声音，
> 就在音源清单里勾上你正在用的那块输出设备。"

**拍摄要点**：三台设备同框，画面里能看出"一个在说、两个在听"（监控窗里 `[广播] 正在广播` 那行）。

#### 2.3 手机当喇叭｜2:50–3:40

**画面**：手机屏幕 + 电脑屏幕同框

**操作步骤**：
```
1. 电脑：打开「广播我的声音」（或建一条把声音送到手机的规则）
2. 手机：打开 Audio Mixing App → 填电脑地址（如 192.168.0.108:17800）
3. 手机点「🔊 当喇叭（放电脑的声音）」→ 手机开始出声
```

**台词**：
> "手机也能当喇叭用。电脑上开广播，手机 App 里填上电脑地址，点这个按钮 ——
> 手机就变成一台无线音箱了。延迟大概一百多毫秒，听歌、开会够用。
> 手机没装 App 也行，扫一下控制台上的二维码，用网页版也能当喇叭，只是延迟会高一点。"

**拍摄要点**：手机出声的那一下要录进去（手机贴近麦克风）。

#### 2.4 手机的声音送进电脑｜3:40–4:30

**画面**：手机 → 电脑

**操作步骤（Wi-Fi 方式，推荐）**：
```
1. 手机装 App，打开，点「发送系统声音」或「发送麦克风」
2. 电脑上：控制台 → 打开「本机直通」
3. 电脑耳机里听到手机的声音
```

**台词**：
> "反过来也行：把手机的声音送到电脑。
> 手机 App 里点「发送系统声音」，电脑上打开「本机直通」—— 手机里的音乐就进电脑了。
> 不想装 App 的话，用蓝牙也能达到类似效果，那部分走的是 Windows 自己的通道。"

**诚实提示**（后期加字）：
```
⚠️ 安卓 10+ 采集系统声音需要用户手动授权（系统隐私策略，任何 App 都一样）
⚠️ 「当喇叭」和「发送声音」在手机上互斥，否则会产生回音
```

#### 2.5 ★ 一台电脑推多个耳机（重点！）｜4:30–5:20

**画面**：一台电脑，插/连两副耳机，两副同时在响

**操作步骤**：
```
1. 电脑上接两副耳机（一副有线 + 一副蓝牙，或两副蓝牙）
2. 控制台 → 多设备输出 → 勾选这两副耳机
3. 播放音乐 → 两副耳机同时出声
```

**台词**：
> "这个功能是我自己最常用的：一台电脑，同时推多个耳机。
> 想和朋友一起看电影、打双人游戏，但声音只能从一个设备出来 —— 这个功能就是为它做的。
> 勾上两副耳机，两边同时响。
> 每一路还能单独调音量、单独调延迟（因为蓝牙耳机延迟不一样，调一下对齐）。"

**拍摄要点**：这是全片最有传播力的一段，建议多给特写 + 慢放。

#### 2.6 监控与诊断｜5:20–5:50

**画面**：监控窗 + 诊断报告

**台词**：
> "它还有个监控窗，能看到谁在给谁发声音、数据量多少、延迟多少、有没有丢包。
> 出问题的时候点一下诊断，它会生成一份完整体检报告，复制给对方看就知道卡在哪。"

### 【第 4 段】与相似产品对比｜6:30–7:40

**画面**：对比表格逐行出现（建议做成动画，逐行高亮）

**台词（配表格逐行念）**：
> "市面上类似的东西我也都试过，说一下区别。

> **蓝牙**：耳机同时只能连一台设备，而且是一对一的链路。想让三台手机的声音进一副耳机，
> 蓝牙的协议就做不了 —— 不是没人做，是做不到。

> **Phone Link（微软手机连接）**：做得很好，但它一次只能接一台手机的声音，
> 而且链路上是"手机到电脑"这一条。它解决不了"多台设备混到一处"。

> **Snapcast**：开源方案里最接近的，但它是"一个服务器推多个播放端"，
> 目标是让多个音箱**同步播放同一路**音频。它需要一台服务器、需要自己提供音源，
> 而且不是"把 N 台设备各自的声音混到一处"。

> **VoiceMeeter + VBAN**：单机混音很强，但每台机器都要装虚拟声卡，
> 跨设备要自己配点对点，对普通用户来说门槛偏高。

> **Sonos / AirPlay 那类**：体验好，但要买硬件，而且只能推自家 App 里的音频。

> **Audio Mixing 的做法不一样**：它不用虚拟声卡（直接采 WASAPI Loopback），
> 不要服务器（任一台都能当控制台），源和目标都是集合 —— 而且免费开源。"

**对比表格（建议整段停留 5 秒让观众截图）**：

| 方案 | 采集系统声音 | 多源混音到一处 | 多目标同时播放 | 免服务器 | 免虚拟声卡 | 花钱 |
|---|---|---|---|---|---|---|
| 蓝牙 A2DP | — | ❌ | ❌ | ✅ | ✅ | 买硬件 |
| Phone Link | 单台手机 | ❌ | ❌ | ✅ | ✅ | 免费 |
| Snapcast | 需自备音源 | ✅（服务器混） | ✅（同步同一路） | ❌ 需服务器 | ❌ | 免费 |
| VoiceMeeter + VBAN | ✅ | ✅（本机） | ⚠️ 点对点 | ✅ | ❌ 要装虚拟声卡 | 免费/收费 |
| Sonos / AirPlay | 只推自家 App | ⚠️ 要硬件 | ✅ | ❌ | — | 买硬件 |
| **Audio Mixing** | ✅ WASAPI Loopback | ✅ 目标端混音 | ✅ 同一路由多目标 | ✅ 去中心 | ✅ | **免费开源** |

**诚实补充（这段别剪掉，能涨信任）**：
> "它也不是万能的：手机采集系统声音必须手动授权，这是安卓和 iOS 的隐私策略，
> 任何第三方 App 都一样；它也没有做跨网络穿透 —— 我给它的定位就是局域网工具，
> 你出门在外用它没意义。想要跨网络的，用 Oopz、Discord 那类方案更合适。"
