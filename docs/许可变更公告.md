# 许可变更公告

## 沿革

| 时间 | 许可证 | 说明 |
|---|---|---|
| 项目初始 | MIT | 宽松许可，允许任何用途 |
| 2026-11-13 | PolyForm Noncommercial 1.0.0 | 限制商业使用，需另行取得商业授权 |
| 2026-11-26 | **Apache License 2.0** | 恢复为 OSI 认证的开源许可，允许商业使用 |

## 变更理由

PolyForm Noncommercial 不是 OSI 认证的开源许可。它会让很多公司、发行版和
开源镜像站无法收录本项目，也会让想学习、二次开发的人先停下来判断“我算不算商业用途”——
这与“把项目开放出来、让更多人用上”的初衷相悖。因此改回 Apache-2.0。

## 不溯及既往

许可证只约束**对应版本发布之后**的使用。已经按旧许可证发布的副本无法收回，
也不会被追认为 Apache-2.0；新许可证从本次变更之后的版本开始生效。

## 商业使用

Apache-2.0 允许商业使用、修改、分发和私有使用，只需保留版权声明与 LICENSE 文件。
如果公司或产品使用了本项目，欢迎开 Issue 告知一声（不强制、不影响授权），
方便了解真实使用场景。
