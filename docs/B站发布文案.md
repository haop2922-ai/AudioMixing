## 二、视频简介（直接粘贴，约 700 字）

```
【它解决什么问题】
想和朋友一起看电影／打双人游戏，但声音只能从一台电脑出来，两个人挤一副耳机？
Windows 一次只能选一个默认输出设备，系统自带的"侦听此设备"要手动配、延迟大、
三个以上设备基本没法用。

我做了个工具解决这件事：Audio Mixing。

【它是什么】
局域网声音投射工具。说人话：把局域网里几台设备的声音，送到你指定的耳机或音箱里。
✅ 只走局域网，不经过任何服务器，不注册、不登录
✅ 20MB 单文件，双击就能用，不用安装
✅ 免虚拟声卡（直接用 WASAPI Loopback 采集系统声音）
✅ 开源免费，MIT 协议

【能做什么】
· 电脑 ↔ 电脑互传声音：对方在放什么，你耳机里就是什么
· 广播（一对多）：一个人说，很多人听
· 手机当喇叭：手机变无线音箱，放电脑的声音
· 手机的声音送进电脑：Wi-Fi 或蓝牙两条路
· ★ 一台电脑同时推多副耳机：勾两副耳机，两边同时响，每路可单独调音量、单独调延迟
· 监控页：谁在给谁发、速率、延迟、丢包一眼看清
· 诊断报告：出问题点一下，生成完整体检报告

【和类似方案的区别】
· 蓝牙：一副耳机同时只能连一台设备，一对一的链路，多源混音它做不了
· Phone Link：一次只能接一台手机的声音，解决不了"多台设备混到一处"
· Snapcast：一个服务器推多个播放端，目标是同步播放同一路音频，需要自己提供音源
· VoiceMeeter + VBAN：单机混音很强，但每台机器都要装虚拟声卡
· Sonos / AirPlay：体验好但要买硬件，而且只能推自家 App 的音频
· Audio Mixing：免虚拟声卡、免服务器、源和目标都是集合，而且免费开源

【下载与源码】
GitHub：https://github.com/haop2922-ai/AudioMixing
（Release 里下载 Audio Mixing v1.2.exe，20MB 单文件）

【运行要求】
· 64 位 Windows 10 / 11
· 手机端需要安卓（APK 也在 Release 里）
· 所有设备连同一个局域网（同一个 Wi-Fi 或同一个交换机）

【第一次运行注意】
1. 会弹一次 SmartScreen（程序没买代码签名）→ 点「更多信息」→「仍要运行」
2. 右下角托盘图标右键 → 「放行防火墙」→ 点「是」
   ★ 这步不做，对方收不到你的声音（这是最常见的失败原因）
3. 换了文件名或目录之后，要重新点一次放行防火墙（规则绑定路径）

【已知限制（不吹）】
· 多设备输出不会自动排除"Windows 正在使用的输出"，勾了它会两路叠加变金属音，别勾那块
· 手机端局域网扫描在部分网络收不到发现广播 → 手输电脑地址即可，二维码不受影响
· 手机当喇叭是 24kHz 单声道（为治手机端断续做的取舍）
· 只有 Windows + Android，没有 USB 模式，没有跨网中继（有意不做，定位就是局域网工具）
· 没有代码签名，首次运行会有安全提示；个别杀软可能误报，允许即可

【验证】
单元测试 102 项全绿；打包闸门：源码语法 + 单元测试 + 页面脚本，任一不过不产出 exe。

开源不易，觉得有用的话点个赞就行，有问题在评论区或 GitHub Issue 里说，
我会看，也会改（这个版本的 9 个 bug 就是靠用户实测反馈修掉的）。

#局域网 #开源 #音频工具 #Windows #效率工具
```

## 四、置顶评论（B站惯例，放下载和常见问题）

```
【下载】
GitHub：https://github.com/haop2922-ai/AudioMixing
Release 里下 Audio Mixing v1.2.exe（20MB 单文件）

【三个最常见的坑】
1. 对方听不到 → 托盘右键「放行防火墙」点了吗？这是 90% 的失败原因
2. 手机当喇叭没声音 → 手机和电脑必须连同一个 Wi-Fi（不能用手机流量）
3. 勾了两个耳机但有杂音 → 别勾"Windows 正在使用的那一块输出"，
   两路叠加会互相抵消（听感像金属音）

【常见问题】
Q：需要注册/付费吗？
A：不需要。MIT 开源，随便用随便改。

Q：会被杀毒软件报毒吗？
A：未签名的单文件 exe 偶尔会被误报（我这版实际遇到过一次），
   允许即可；源码全在 GitHub 上，可以自己编译。

Q：能跨网络用吗（比如我在外地连家里的电脑）？
A：不能，也不打算做。这个工具的定位就是局域网，
   跨网络请用 Oopz、Discord 那类方案。

Q：Mac / iPhone 能用吗？
A：暂时不能，只有 Windows + Android。

Q：我提交的 bug 会修吗？
A：会。v1.2 这一版修的 9 个问题全部来自用户实测反馈。
```
