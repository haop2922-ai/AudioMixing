# Audio Mixing 应用简介

## 一句话（30 字）

把局域网里几台设备的声音，送到你指定的耳机里。免服务器、免虚拟声卡、开源免费。

## 简介（约 120 字，可直接用）

Audio Mixing 是一个局域网声音投射工具：把同一个局域网里几台设备的声音，送到你指定的耳机或音箱里。

不用服务器，不用注册，不用装虚拟声卡，20 MB 单文件双击就能用。

电脑之间能互传声音，能一个人说多人听，能让手机当喇叭，也能让一台电脑同时推多副耳机。

Windows + 安卓，MIT 开源免费。
GitHub：github.com/haop2922-ai/AudioMixing

## 第一次用

1. 双击程序，首次弹 SmartScreen 就点「更多信息」→「仍要运行」
2. 托盘图标右键 →「放行防火墙」→ 点「是」
3. 在要听的那台建一条路由：从对方电脑 → 到本机 → 添加

## 照实说的限制

多设备输出别勾「Windows 正在用的那块输出」（会变金属音）；手机当喇叭是 24 kHz 单声道；
只有 Windows + 安卓，不做跨网络；没有代码签名，首次运行会有系统提示。
